# ADR-0003: Hệ tọa độ cố định 540×960 dọc

- **Trạng thái:** Chấp nhận
- **Ngày:** 2026-11-16
- **Liên quan:** `config.yaml` → `screen`, mọi ROI trong `bot/`, `templates/`

## Bối cảnh
Template matching OpenCV không bất biến tỉ lệ; ROI OCR và tọa độ nút cần ổn định.

## Quyết định
Mọi instance LDPlayer đặt **540×960, 240 DPI, dọc**. Toàn bộ ảnh mẫu, ROI (`gather.*_roi`, `ocr.TOPBAR`…), tọa độ cứng trong code đều theo hệ này. Riêng thiết bị cảm ứng thô (`/dev/input/event2`) có trục tỉ lệ khác: `X_touch = x·960/540`, `Y_touch = y·540/960` (đo từ bản ghi thao tác thật).

## Hệ quả
- Tốt: đơn giản, không cần chuẩn hóa tỉ lệ; ảnh mẫu dùng chung cho mọi instance.
- Xấu: instance đặt sai độ phân giải → bot "mù". Đổi độ phân giải = cắt lại toàn bộ ảnh mẫu.
- Ngưỡng khớp mặc định `match_threshold: 0.82`; phần tử có hoạt ảnh dùng ngưỡng riêng thấp hơn (vd V-marker ~0.75, tab mỏ 0.72).
