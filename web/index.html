Agent quyết định gì

Agent chỉ chạy trên máy khi cả hai: công tắc chung bật (nút bên phải, mặc định TẮT) và máy đó chọn chế độ "Agent" (ô Chế độ của từng máy). Công tắc chung tắt → các máy chọn Agent chạy theo lịch chung — dùng làm nút dừng khẩn cấp. Xem thử không chạm game: python -m aowbot plan 1 · python -m aowbot shadow all
